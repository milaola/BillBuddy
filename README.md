# Bill Buddy 
Bill Buddy is a web application for tracking and managing recurring subscruptions. It allows users to add subscriptions, view thier recurring expenses, filter and search subscriptions and see spending insights. 

## Features

- Add new subscriptions
- Validate subscription names and amounts
- Select subscription categories
- Select monthly or yearly billing cycles
- Track upcoming payment dates
- Display payment status
- Search subscriptions
- Filter subscriptions by category
- Delete subscriptions
- Calculate monthly and yearly spending
- View spending insights by category
- Identify the most expensive subscription
- Store subscription data using LocalStorage
- Import subscriptions from a JSON file
- Export subscriptions as a JSON file
- Load categories using the Fetch API
- Use asynchronous JavaScript with async and await
- Jest unit testing

## Technologies Used 

- HTML5
- CSS3
- JavaScript
- Node.js
- Jest
- LocalStorage API
- DOM API
- Fetch API
- FileReader API
